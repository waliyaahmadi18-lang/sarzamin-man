# MY HOMELAND — Afghanistan
A responsive tourism and cultural showcase built with semantic HTML5, external CSS3 and vanilla JavaScript.

## Run
Open `index.html` with VS Code Live Server. Internet is required because the photographs are loaded from Wikimedia Commons and fonts from Google Fonts.

## Included requirements
- Semantic header, navigation, main, sections and footer
- Responsive CSS Grid/Flexbox and media queries
- Hover transitions, mobile navigation, English/Dari language toggle
- Enquiry form with client-side validation and demo confirmation
- 25+ documentary photographs from Wikimedia Commons (remote URLs)

## Image credits and use
Photographs are served from Wikimedia Commons via Special:FilePath. Please check each file's attribution and license before publishing or reusing it commercially. Selected sources include Wikimedia Commons categories for Afghan clothing, jewellery, carpets and food, plus individual files for Bamiyan, Kabul, Herat, Mazar-i-Sharif and Ghor. Images require an internet connection.

Note: this is an educational tourism website mock-up. The enquiry form does not transmit or store submitted information.
